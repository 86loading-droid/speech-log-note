천천히 반복 버튼은 학생이 방금 말한 목소리를 위 속도로 늦춰 여러 번 들려줍니다. 목소리의 높낮이는 그대로 두고 속도만 늦추므로 조음을 살피기 좋습니다. 버튼에 진행 횟수가 표시되고, 다시 누르면 언제든 멈춥니다.

다음 발화가 없어도 이 시간이 지나면 화면의 발화가 자동으로 기록됩니다. 글자는 화면에 그대로 남고 배지만 기록됨으로 바뀝니다. 교사가 확인을 깜빡해도 기록이 누락되지 않습니다.

보관 시간은 1시간으로 고정되어 있습니다. 녹음과 낱말 모델 모두 만든 때부터 1시간이 지나면 자동으로 지워지며, 이 값은 설정으로 늘리거나 줄일 수 없습니다. 음성은 이 기기 안에만 남고 서버로 보내지 않습니다.

목소리 복제로 읽기 무료 경로와 유료 경로

    
학생 목소리를 복제해 화면의 글을 그대로 읽어 줍니다. 낱말이나 음절을 미리 잘라 두지 않아도 되며, 처음 보는 문장도 읽습니다. 합성은 학교 밖 서버에서 이루어지므로 보호자 서면 동의를 받은 학생에게만 쓰십시오.

    
무료 경로 — 구글 코랩 무료 GPU 에서 XTTS-v2 를 돌리는 방식입니다. 카드 등록 없이 0원입니다. 저장소의 코랩 노트북을 열어 칸 두 개를 실행하면 주소와 공유 암호가 나옵니다. 코랩은 한 번에 최대 12시간이고 손을 떼면 90분쯤 뒤 끊기며, 다시 실행하면 주소가 바뀌므로 앱에 새 주소를 넣으셔야 합니다.

    
유료 경로 — fal.ai 를 쓰면 한도 없이 즉시 응답합니다. 등록은 1분에 약 0.0008달러, 읽기는 1000자에 약 0.07달러입니다. 20자 문장 한 번이 약 2원이고 구독이 아니라 쓴 만큼만 청구됩니다.


    
    

    
    

    

      
    

    
복제 서버 주소를 넣지 않으면 복제 읽기 버튼이 화면에 나타나지 않습니다.


    
학생별 목소리 등록

    
지금 화면에 담겨 있는 녹음을 참조로 보내 그 학생의 목소리를 만듭니다. 10초 이상이면 실용적이고 30초 이상이면 더 닮습니다. 이 기기에는 목소리 파일 주소만 저장되며, 사용을 마치면 해제하십시오.

    


    

    
자주 틀리는 말 교정

    
특정 낱말이 반복해서 잘못 인식되면 규칙을 등록하십시오. 인식된 문장에서 자동으로 바꿔 줍니다. 바뀌기 전 원문도 함께 보관되어 통계 탭에서 실제 인식률을 분석할 수 있습니다.

    2. 
      
  2. Google 앱(태블릿의 음성 인식을 맡는 앱) — 설정 → 애플리케이션 → Google → 권한 → 마이크 → 「앱 사용 중에만 허용」. 목록에 「Google 음성 인식 및 합성」이 있으면 그 앱도 같은 방법으로 허용합니다.
    3. 
      
  3. 이 사이트 — Chrome 주소창 왼쪽 아이콘을 누르고 권한 → 마이크 → 허용. 또는 Chrome ⋮ → 설정 → 사이트 설정 → 마이크에서 86loading-droid.github.io 를 허용합니다. 처음 묻는 창이 뜨면 「이번만 허용」이 아니라 「사이트 방문 중 허용」을 누릅니다.
